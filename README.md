# CRYPTA — Крипто Торговый Симулятор

Образовательный симулятор криптовалютной торговли с виртуальными $10,000 USDT. Реалистичный интерфейс, технический анализ, обучение и челленджи — всё в одном месте.

## ⚠️ ВАЖНО

Это **образовательный симулятор**. Никаких реальных денег, транзакций или подключения к кошелькам. Все цены и сделки симулируются.

## 🚀 Быстрый старт

### Предrequisites
- Node.js 18+ 
- npm или yarn

### Установка и запуск

```bash
# 1. Установите зависимости
npm install

# 2. Запустите dev-сервер
npm run dev

# 3. Откройте в браузере
http://localhost:5173
```

### Сборка для продакшена

```bash
npm run build
npm run preview
```

## 📦 Деплой (бесплатный хостинг)

### Vercel (рекомендуется)

1. Заpushте код на GitHub
2. Зайдите на [vercel.com](https://vercel.com)
3. Нажмите "New Project" → импортируйте репозиторий
4. Vercel автоматически определит Vite и соберёт проект
5. Получите ссылку вида `https://crypta-xxxx.vercel.app`

### Netlify

1. Заpushте код на GitHub
2. Зайдите на [netlify.com](https://netlify.com)
3. "New site from Git" → выберите репозиторий
4. Build command: `npm run build`
5. Publish directory: `dist`
6. Нажмите "Deploy"

### GitHub Pages

```bash
npm install -g gh-pages
npm run build
gh-pages -d dist
```

## 🎮 Возможности

### 📊 Дашборд
- Обзор портфеля в реальном времени
- Открытые позиции и PnL
- Список наблюдения (Watchlist)
- Обзор рынка с топ-монетами
- Последние сделки

### 💹 Торговый терминал
- Интерактивный график свечей (Recharts)
- Таймфреймы: 1м, 5м, 15м, 1ч, 4ч, 1Д
- Технические индикаторы: SMA, EMA, RSI, MACD, Bollinger Bands
- Типы ордеров: Рыночный, Лимитный, Стоп-лосс, Тейк-профит
- Кредитное плечо до 20x
- Автоматическое исполнение ордеров

### 📈 Портфель
- Детальная статистика PnL
- Распределение активов (pie chart)
- График производительности
- Win rate, средняя прибыль/убыток
- Risk/Reward ratio

### 📜 История сделок
- Полная таблица всех сделок
- Фильтрация по типу (Buy/Sell)
- Сортировка по дате, активу, PnL
- Подробная информация о каждой сделке

### 🔍 Рынки
- Обзор всех доступных криптовалют
- Фильтры по категориям (Layer 1, DeFi, L2, Stablecoins)
- Сортировка по цене, объёму, капитализации
- Быстрый переход к торговле

### 📚 Обучение (Learn)
- 26 уроков (10 beginner, 10 intermediate, 6 advanced)
- Интерактивные квизы
- Отслеживание прогресса
- Темы: Bitcoin, Ethereum, блокчейн, индикаторы, риск-менеджмент и др.

### 🎯 Челленджи
- 6 практических заданий
- Система XP (очков опыта)
- Бейджи за достижения
- Практическое применение знаний

### 📰 Новости
- Симулированные рыночные новости
- Фильтрация по настроению (бычье/медвежье/нейтральное)
- Очевидно маркировано как SIMULATED

### 📖 Гайд
- Пошаговые руководства
- Советы по торговле
- FAQ
- Справочная информация

### ⚙️ Настройки
- Переключение языка (EN/RU)
- Тёмная/светлая тема
- Скорость симуляции
- Начальный баланс
- Сброс демо-аккаунта

## 🛠 Технологии

- **React 19** + **TypeScript**
- **Vite** — сборка и dev-сервер
- **Tailwind CSS v4** — стилизация
- **Recharts** — графики и диаграммы
- **Lucide React** — иконки
- **Zustand** — управление состоянием
- **React Router v7** — маршрутизация
- **LocalStorage** — персистентность данных

## 🎯 Как пользоваться

1. **Начните с Дашборда** — посмотрите обзор портфеля
2. **Перейдите в Торговый терминал** — выберите монету и разместите первый ордер
3. **Изучите раздел Learn** — пройдите уроки по основам торговли
4. **Выполняйте Челленджи** — получайте XP и бейджи
5. **Отслеживайте прогресс** в Портфеле и Истории
